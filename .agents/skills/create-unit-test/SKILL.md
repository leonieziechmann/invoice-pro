# Creating a Unit / Calculation Test

This skill guides you through creating a fast, deterministic unit test or calculation test in `invoice-pro` without invoking heavyweight ZUGFeRD / PDF/A-3b validations.

## When to Use This Workflow

- Testing line-item math (discounts, surcharges, gross/net distribution, roundings).
- Testing tax aggregation and group-by-tax logic.
- Testing bug regressions that do not involve PDF visual layout or XML generation.

---

## Step-by-Step Procedure

### 1. Choose Directory Location

- **Line-item / Math calculation test**: `tests/line-items/<test-name>/`
- **Issue regression test**: `tests/issues/issue-<number>/`
- **Unit logic test**: `tests/unit/<test-name>/`

### 2. Create the Directory and Required `.gitignore`

Create `tests/<category>/<test-name>/.gitignore` with:

```gitignore
# generated by tytanic, do not edit

/diff/
/out/
```

### 3. Create `test.typ`

Use `data-test`, `test-locale`, and `themes.blank` for lightweight assertions:

```typ
#import "/src/lib.typ": *
#import "/tests/data-test.typ": data-test, loom
#import "/tests/test-locale.typ": test-locale

#show: invoice.with(
  theme: themes.blank,
  locale: test-locale,
  sender: (name: "Test Sender"),
  recipient: (name: "Test Recipient"),
  invoice-nr: "UNIT-001",
)

#data-test(test: (ctx, data) => {
  let line-items = loom.query.find-signal(data, "line-items")
  assert.ne(line-items, none, message: "line-items signal not found")

  // Validate exact decimal computations
  assert.eq(
    line-items.totals.net-total,
    decimal("100.00"),
    message: "Net total: expected 100.00, got " + repr(line-items.totals.net-total),
  )
})[
  #line-items[
    #item(
      [Test Product],
      price: 100.00,
      quantity: 1,
      tax: tax.vat(19%),
    )
  ]
]
```

### 4. Key Rules

- Always use `decimal("...")` for monetary comparisons to avoid float precision errors.
- Always provide clear assertion failure messages: `"Field: expected <val>, got " + repr(actual)`.
- If using bank details, use valid IBAN (`DE75512108001245126199`) and BIC (`SOLADEST600`).
- If this is an issue regression test, register it in `tests/TESTING.md` under **Issue Test Registry**.

### 5. Run and Verify

```bash
# Run only this test
tt run "<category>/<test-name>"
# or with Nix
nix develop .#test --command tt run "<category>/<test-name>"
```
